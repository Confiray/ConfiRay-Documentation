# Blueprint ConfiRay

> **Straight Line to Automation**

Blueprint ConfiRay je hlavní strategický dokument platformy ConfiRay.

Není to marketingový materiál ani uživatelská příručka.

Je to dokument, který popisuje proč ConfiRay vzniká, jakou má vizi, jaké problémy řeší, jak bude platforma fungovat a jakým směrem se bude dlouhodobě vyvíjet.

Blueprint slouží jako společný referenční bod pro zakladatele, vývojáře, obchodníky, implementační konzultanty i budoucí zaměstnance.
